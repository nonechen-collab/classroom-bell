# 教室作息系統（網頁版・第 1 階段：作息提醒）

不用安裝程式，用 Chrome 或 Edge 開網址就能用。鐘響前 20 秒倒數，鐘響後依項目提醒或計時。

## 兩種用法

| 情況 | 用法 |
|---|---|
| 下課時間，大螢幕顯示這個網頁 | 平常是大時鐘；時間到全螢幕倒數、計時，30 秒後縮成右上角卡片 |
| 上課開電子書 | 按「🗗 浮動視窗」：角落出現永遠在最上層的小視窗，時間到就在裡面倒數、計時 |

大螢幕切到 Android 手寫白板時，看不到 Windows 畫面，倒數也看不到。

## 目前完成的功能

- 作息時間表：早自習、打掃、第一～八節、午餐、午休，可在設定頁增刪改、停用
- 鐘響前倒數（預設 20 秒，最後 5 秒變紅）
- 打掃：提醒 30 秒後回到時鐘
- 就位計時：0.1 秒計時；30 秒後縮成角落卡片繼續計時，最多 5 分鐘
- 午餐：顯示剩餘時間，一直到中午打掃倒數出現
- 關閉：按畫面上的「✕ 關閉」或 Esc
- 暫停：跳過下一個項目、暫停 1 小時、暫停到今天結束
- 放假日、補上課日、時間微調
- 就位紀錄與 CSV 匯出
- 「模擬」按鈕：20 秒後鐘響，不列入紀錄
- 離線也能用（學校網路斷線時照常倒數）

第 1 階段還沒有鏡頭辨識：就位計時由老師按住「全班就位」停止。

## 開機自動開啟

1. 用 Chrome 或 Edge 開網址，網址列右邊按「安裝」，網頁會變成獨立視窗的應用程式（不是 exe，Windows 不會擋）。
2. 到 `chrome://apps`（Edge：`edge://apps`），在「教室作息系統」上按右鍵 →「登入時啟動」。
3. 每天開機後點一下畫面，浮動視窗就會打開（瀏覽器規定要有人點一下）。

## 資料存放

設定和紀錄存在那台電腦的瀏覽器裡。清除瀏覽器資料會一起清掉；第 5 階段會加上雲端同步。

## 開發

需要 Node.js 22 以上，不需要安裝任何套件。

```bash
npm test          # 時間表與狀態機的自動測試
npm start         # 本機測試：開 http://localhost:5173
npm run icons     # 重新產生圖示
```

要部署時，把 `web/` 資料夾的內容放上任何靜態網站空間（例如 GitHub Pages）即可。每次更新記得把 `web/sw.js` 裡的 `VERSION` 加 1。

| 檔案 | 用途 |
|---|---|
| `web/js/schedule.js` | 預設時間表、某天有哪些項目、格式檢查 |
| `web/js/engine.js` | 狀態機：何時倒數、提醒、計時、縮小、關閉、暫停 |
| `web/js/store.js` | 設定與紀錄（瀏覽器 localStorage） |
| `web/js/views.js` | 畫面元件（全螢幕、角落卡片、浮動視窗共用） |
| `web/js/app.js` | 主頁接線：計時器、浮動視窗、暫停選單 |
| `web/js/settings.js` | 設定頁 |
| `web/sw.js` | 離線快取 |
