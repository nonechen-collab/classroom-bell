兩種用法

  • 大螢幕顯示這個網頁（下課時間）：平常是大時鐘，時間到會全螢幕倒數、計時。按右下角「⛶ 全螢幕」或鍵盤 F11。
  • 上課開電子書時：按「🗗 浮動視窗」，角落會出現永遠在最上層的小視窗，時間到就在小視窗裡倒數、計時。小視窗可以拖曳位置、拉角落改大小。

關閉與暫停

  • 按畫面上的「✕ 關閉」或鍵盤 Esc 就會關閉。「✓ 全班就位」要按住約 1 秒，避免學生誤觸。
  • 「⏸ 暫停」可以跳過下一個項目、暫停 1 小時、暫停到今天結束（段考、活動日）。

開機自動開啟

  1. 用 Chrome 或 Edge 開啟這個網址，網址列右邊按「安裝」（或選單 →「投放、儲存與分享」→「將網頁安裝為應用程式」）。
  2. 到 chrome://apps（Edge 是 edge://apps），在「教室作息系統」上按右鍵，勾選「登入時啟動」。
  3. 每天開機後，在畫面上點一下就會開啟浮動視窗。

注意

  • 大螢幕切到 Android 手寫白板時，看不到 Windows 畫面，所以也看不到倒數。
  • 設定和紀錄存在這台電腦的瀏覽器裡。清除瀏覽器資料會一起清掉，之後會加上雲端同步。
  • 第 1 階段還沒有鏡頭辨識：就位計時要由老師按住「全班就位」停止。
